# Online Retail Sales Analysis using SQL

## Project Overview
This project analyzes an Online Retail Sales dataset using MySQL to identify customer purchasing behavior, product performance, country-wise sales, and revenue trends.

## Tools Used
- MySQL
- SQL
- Microsoft Word
- GitHub

## Dataset
- 541,909 transaction records
- 3,958 unique products
- 4,373 unique customers
- 38 countries

## Project Phases
### Phase 1
- Raw Data Exploration
- Missing Values
- Duplicate Check
- Negative Quantity Analysis
- Cancelled Invoice Analysis

### Phase 2
- Business Analysis
- Customer Analysis
- Product Analysis
- Country Analysis
- Sales Trends

### Phase 3
- Data Cleaning
- Removed Duplicate Records
- Removed Cancelled Transactions
- Created Retail_Final dataset

### Phase 4
- Exploratory Data Analysis
- Customer Lifetime Revenue
- Product Performance
- Revenue Contribution
- Country Revenue
- Monthly Sales Trends

## Key Business Insights
- Top 10 customers generated 17.44% of total revenue.
- United Kingdom generated the highest revenue.
- A small number of customers contributed a large share of total sales.
- Revenue is concentrated among a limited number of products.
- November recorded the highest monthly revenue in 2011.
